# Перепривязка болванок к уровням

Опция в окне «Обновить отметки» действует только на текущий запуск. Она не сохраняется в XML и не включает перепривязку в автоматическом апдейтере.

## Поведение

- «Автоматически»: для болванок стен выбирается ближайший уровень снизу, для плит — ближайший по высоте.
- «К выбранному уровню»: доступно только в режиме «В выбранных элементах». Переключение на весь проект сбрасывает ручной режим и выбранный уровень.
- При включении галочки появляется короткое предупреждение о необходимости проверить результат.
- Без галочки болванка без уровня пропускается с подсказкой включить перепривязку. Отсутствующий обязательный параметр также даёт понятный пропуск; другие элементы продолжают обновляться.
- В результате перечисляются количества, причины и ID пропущенных элементов. Их можно выделить кнопкой отчёта.
- Готовые отверстия и гильзы сохраняют обычное обновление отметок, без смены уровня.

## Геометрия и уровни

Поддержаны свободные вертикальные семейства `OneLevelBased` категории «Обобщенные модели»: коды 111–116 и 121–124. При пустом коде распознаются четыре стандартных имени `Пересечение_Стена/Плита_Прямоугольное/Круглое`. Несовместимые сочетания имени и кода не перепривязываются.

Источник положения — `LocationPoint.Point`, а не общие отчётные параметры. Для прямоугольной стены это низ, для круглой — центр. У плиты опорная высота равна Z точки вставки минус 50 мм, согласно геометрии штатных создателей.

Подбор использует `Level.ProjectElevation`, независимо от базы отображаемых отметок. Несколько одинаково подходящих уровней считаются неоднозначностью. Если для стены нет уровня снизу, элемент пропускается. Эти случаи разрешаются явным выбором уровня.

У экземпляра, созданного скриптом без уровня, прежнее смещение не используется. После назначения уровня новое встроенное смещение вычисляется как `savedPoint.Z - target.ProjectElevation`. Поправка 50 мм не вычитается повторно из встроенного смещения.

Для изменения положения используется доступный для записи `INSTANCE_ELEVATION_PARAM`; для плиты допускается совместимый `INSTANCE_FREE_HOST_OFFSET_PARAM`. Проверяется связь параметра с реальной Z. У экземпляра без уровня доступность смещения проверяется после назначения уровня и регенерации. Если параметр нельзя изменить, экземпляр откатывается с причиной.

Прежняя формула отчётных параметров сохранена: высота базового уровня берётся из `Level.Elevation`, а смещение плиты — из `INSTANCE_FREE_HOST_OFFSET_PARAM - 50 мм`.

## Защита изменений

Экземпляры не пересоздаются. Проверяются точка вставки, полный transform, габариты, основные размеры, тип и `GH_GUID` — до завершения транзакции и после неё. Непредусмотренное изменение откатывает элемент. Отдельно включённое округление выполняется после проверки перепривязки и может менять положение.

Групповые, вложенные, закреплённые, наклонённые и размещённые на основе болванки не перепривязываются автоматически. Для них выводится причина. Обычный путь обновления сохраняет штатную обработку предупреждений Revit; перепривязка отменяется при предупреждениях, чтобы Revit не исправлял геометрию неявно.

Весь запуск объединён в один Undo. Ошибки отдельных элементов изолированы. Ошибка регенерации прерывает всю операцию. Апдейтер GloryHole временно приостанавливается на все транзакции и возвращается в прежнее состояние. Ошибка его восстановления выводится отдельно от результата сохранения модели.

## Автоматическая проверка

```powershell
dotnet test .\GloryHoleRefreshElevations.Tests\GloryHoleRefreshElevations.Tests.csproj
dotnet build .\GloryHoleRefreshElevations\GloryHoleRefreshElevations.csproj -c R2023
```

Пройдены 96 тестов: 83 расчётов и 13 жизненного цикла апдейтера. Они работают без установленного Revit и не заменяют проверку параметров и регенерации в реальной модели.

На 2026-10-05 WPF проверен отдельным STA-приложением с настоящими XAML и CitrusTheme: 38 проверок, включая окна предупреждений, переключение режимов, запись чисел, отсутствие новых флагов в XML, клавишу Space и прокрутку при ограниченной высоте. Проверена отрисовка при 100% и 150%.

Сборки R2019–R2026 прошли. Для R2026 закреплён пакет API 2026.0.0: плавающая версия подтягивала 2026.5 с зависимостью от .NET 10 даже из папки `net8`. Это сохраняет совместимость с исходной платформой Revit 2026 на .NET 8. В репозитории обновлена распространяемая DLL для Revit 2023, соответствующая прежней версии API этого файла.

Revit 2027 не входит в подтверждённую матрицу этой функции. Его конфигурация и SDK обновляются отдельной задачей; изменения этой миграции не включены в коммит перепривязки.

## Проверка в Revit перед использованием на рабочей модели

1. На копии модели создать штатные болванки стен и плит без уровня тем же скриптом замены. Без перепривязки проверить понятный пропуск и успешную обработку соседних корректных элементов.
2. Включить автоматическую перепривязку и выключить оба округления. Сравнить положение, ориентацию, размеры, уровень, смещение и `GH_GUID` до и после для прямоугольных и круглых профилей.
3. Проверить скопированные между этажами болванки с существующей привязкой, а также модель с изменённой базой отображения отметок.
4. Для выбранных элементов указать уровень выше болванки: отрицательное смещение допустимо, геометрия должна сохраниться. У всего проекта ручной режим должен быть недоступен.
5. Проверить одинаковые уровни, равные расстояния до уровней плит, отсутствие нижнего уровня стен, группы, вложенные/закреплённые/наклонённые экземпляры и параметры только для чтения.
6. Повторить с включённым и выключенным апдейтером, с округлением и без него. Проверить сохранение состояния апдейтера и единую команду Undo.

Эти проверки геометрии в Revit остаются обязательной ручной приёмкой: автоматически запуск на пользовательской модели не выполнялся.
