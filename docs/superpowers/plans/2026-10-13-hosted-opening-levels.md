# Перепривязка готовых отверстий

Запрос: распространить «Перепривязать к уровням» на готовые отверстия и гильзы, сохраняя реальные вырезы и положение. Разработка в master, затем сборки R2019–R2027 и публикация исходников. Настройки не менять.

## Решение

- Отдельная классификация готовых отверстий CITRUS и поддерживаемых семейств WEANDREVIT. Путь свободных заданий сохраняется.
- Только реальный `FAMILY_LEVEL_PARAM` и подтверждённый `FamilyInstance.LevelId`. `Schedule Level` не заменяет уровень размещения. Экземпляры не пересоздаются.
- Для стен автоматический выбор ближайшего нижнего уровня; для плит ближайший по высоте к точке вставки. Поправка 50 мм остаётся только у заданий в плитах. Ручной выбор доступен для выбранных элементов.
- Сохранить мировое положение, тип, GUID, ориентацию, размерные параметры экземпляра/типа, основу и её грань, существующие связи вставки, вырезания и соединения. BoundingBox не использовать.
- Невозможная перепривязка, изменение геометрии или предупреждение Revit откатывают элемент с причиной. Ошибка регенерации прерывает операцию. Закреплённые, групповые и вложенные элементы сохраняют явный пропуск.
- Исправить отчётные отметки готовых стеновых отверстий с кодом 126 и плит: `hostLevel.ProjectElevation + hostOffset - openingLevel.ProjectElevation`. Согласовать формулу с автоматическим апдейтером RibbonCITRUS.

## Проверки и выполнение

1. Исследовать создатели семейств и Revit API 2019–2027; проверить точные API по локальным сборкам и Autodesk.
2. Записать регрессионные тесты существующего сервиса с ограниченными Revit stubs; подтвердить падение на готовых отверстиях. Добавить чистые тесты классификации/отметок.
3. Реализовать готовые отверстия, проверки транзакций и параметров, обновить интерфейс и документацию.
4. Независимо проверить откаты после commit, недоступный уровень, основы и соединения, компенсацию плит и отсутствие регрессии заданий.
5. Прогнать тесты и сборки R2019–R2027. Сохранить настройки и посторонние изменения. Коммитить и отправить только относящиеся к задаче файлы; дать ссылки на bin.

Автотесты моделируют только API-переходы и расчёты. Проверку геометрического ядра и конкретных RFA/RVT в установленном Revit они не заменяют.
